## 设计与扩展结构

参考 [Flaq 官方站](https://flaq.ai/)
的黑色/炭灰底色、紫色主操作、低对比边框和卡片视觉，继续复用原项目的表单、模型图标、示例素材和预览组件；桌面版缩减侧栏宽度、提高工作台文字可读性，将长介绍收进弹窗。不是重新制作一套无关的 UI，也不宣称与官网逐像素一致。

模块边界分为功能注册、模型契约、产品组件、服务适配、轮询调度和原生平台能力。后续新增模块的具体步骤、测试门槛和性能约束见
[模块扩展指南](ADDING_MODULES.md) 与 [架构说明](DESKTOP_ARCHITECTURE.md)。

## 尚未验收的范围与发布前事项

1. 没有真实 Flaq Client Key /
   R2 凭据：真实生成、参考素材上传、模型计费、服务端超时行为和公开素材域名仍需实际账号验收。当前 R2 联通测试验证写入，会留下一个小型测试对象；它不单独证明公开域名可读。
2. Windows、Linux 已配置构建矩阵，但未在本次环境运行；不能宣称三端均已实机验证。macOS 的原生保存弹窗完整链路与 FFmpeg 裁剪仍需专项 UI 验收，不能以 helper 测试替代。
3. 桌面版记住的 Client Key 按产品决定以明文存入用户配置目录的 `auth.json`，不使用系统密钥库或应用加密。共享设备应不勾选“记住我”，发布前仍需按部署范围收紧网络权限和 CSP。
4. macOS 包目前未签名、未公证；Windows 签名与各系统安装/卸载体验未验收。
5. 15 种语言键集合已覆盖，但逐语种翻译质量、每个模型的全部参数组合与所有媒体格式未人工穷举。上游存在英文回退：实测阿拉伯语下部分导航、生成按钮和历史标题仍为英文，另有英文模型枚举标签。桌面新增词条已提供对应语言，不能把原有词条的“键存在”当成“完整翻译”。

因此本轮交付为“已修复关键缺口并通过明确范围内的验证”，不是“所有环境与外部服务保证无问题”。
