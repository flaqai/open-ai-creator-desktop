and premium rather than cluttered. Generous clear margins and breathing room; artwork and title do not overlap. Use

robot/brain/circuit illustration. Banner aspect ratio approximately 3:1, horizontal. This is a conceptual brand banner,
not an application screenshot. No fake UI controls, no extra words, no watermark, no third-party logos, no claims about
pricing or performance. Render "Flaq Open Media Creator" verbatim and unobscured.
