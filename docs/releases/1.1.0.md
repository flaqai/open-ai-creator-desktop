## 中文

Flaq Creator 1.1.0 是一次桌面端内容体验、媒体管理与连接稳定性更新。本版本提供 macOS Apple Silicon、macOS
Intel 和 Windows x64 安装包。

### 新功能与改进

- 新增素材库，内置 Qwen Image 3.0、Wan 3.0、MiniMax H3 和 Seedance 2.5 分类的完整提示词与示例素材。
- 全新提示词详情查看器：保留原图比例，支持 100%–300% 缩放、拖动查看、三态分栏和小屏响应式布局。
- 生成历史移入设置中心，支持图片与视频预览、下载和本地媒体管理。
- 桌面端“记住我”改用与端口无关的 `auth.json` 保存 Client Key，并补充授权检测和脱敏日志。
- 改进生成请求与媒体归档的瞬时网络错误重试，降低“生成成功但保存失败”的概率。
- 安装包可携带打包时加密的默认 Cloudflare R2 预设，同时保留自定义 R2 预设。
- Windows 新增与应用主题一致的桌面标题栏和窗口控件。

### 下载选择

- Apple Silicon Mac（M1/M2/M3/M4 等）：`Flaq-Creator-macos-arm64.dmg`
- Intel Mac：`Flaq-Creator-macos-x64.dmg`
- Windows 10/11 x64：推荐 `Flaq-Creator-windows-x64-setup.exe`；需要 MSI 部署时选择 `Flaq-Creator-windows-x64.msi`
- `SHA256SUMS` 和 `release-manifest.json` 用于校验下载完整性与构建来源。

### 安装提示

当前安装包尚未使用 Apple Developer ID 或 Windows 代码签名。首次打开时，macOS Gatekeeper 或 Windows
SmartScreen 可能显示安全提示。

## English

Flaq Creator 1.1.0 improves desktop content discovery, media management, and connection reliability. This release
includes installers for macOS Apple Silicon, macOS Intel, and Windows x64.

### What’s new

- Added a curated media library with complete prompt examples for Qwen Image 3.0, Wan 3.0, MiniMax H3, and Seedance 2.5.
- Introduced a redesigned prompt-detail viewer that preserves source aspect ratios and supports 100%–300% zoom, panning,
  three panel modes, and responsive small-screen layouts.
- Moved generation history into Settings with image and video previews, downloads, and local media management.
- Desktop “Remember me” now stores the Client Key in a port-independent `auth.json`, with improved authorization
  diagnostics and redacted logs.
- Added retry handling for transient generation-request and media-archive failures, reducing cases where generation
  succeeds but local saving fails.
- Packaged installers can include a build-time encrypted default Cloudflare R2 preset while retaining reusable custom R2
  presets.
- Added a theme-aware native-style title bar and window controls on Windows.

### Which file should I download?

- Apple Silicon Mac: `Flaq-Creator-macos-arm64.dmg`
- Intel Mac: `Flaq-Creator-macos-x64.dmg`
- Windows 10/11 x64: use `Flaq-Creator-windows-x64-setup.exe`, or `Flaq-Creator-windows-x64.msi` for MSI deployment.
- Use `SHA256SUMS` and `release-manifest.json` to verify download integrity and build provenance.

### Installation note

These installers are not yet signed with an Apple Developer ID or Windows code-signing certificate. macOS Gatekeeper or
Windows SmartScreen may display a security warning on first launch.
