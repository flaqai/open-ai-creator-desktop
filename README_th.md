# Flaq SaaS Template (ภาษาไทย)

เทมเพลต SaaS ฟรีและโอเพนซอร์สสำหรับสร้างแพลตฟอร์มสร้างภาพและวิดีโอด้วย AI ผ่าน API แบบรวมของ Flaq.ai

## เกี่ยวกับ Flaq.ai

[Flaq.ai](https://flaq.ai/th/) เป็นแพลตฟอร์มโมเดล AI สำหรับครีเอเตอร์และนักพัฒนา ใช้ API key
เดียวเพื่อเข้าถึงการสร้างและแก้ไขภาพ การสร้างวิดีโอ และโมเดลภาษาได้ผ่าน API แบบรวม

- **ค้นหาและเปรียบเทียบโมเดล** — ดูความสามารถ พารามิเตอร์ที่รองรับ และราคาปัจจุบันได้ที่
  [Model Market](https://flaq.ai/model-market/)
- **ทดลองก่อนเชื่อมต่อ** — ใช้ Playground ของ Flaq.ai ทดสอบโมเดลที่รองรับและปรับพรอมป์ต์กับการตั้งค่าการสร้าง
- **สร้างเวิร์กโฟลว์งานสร้างสรรค์** — ใช้[เอกสาร API](https://flaq.ai/docs/)เพื่อเชื่อมต่อ AI
  เข้ากับผลิตภัณฑ์และเครื่องมือของคุณ

Flaq Creator Desktop นำเวิร์กโฟลว์ภาพและวิดีโอมาไว้ในพื้นที่ทำงานเดสก์ท็อปโดยเฉพาะ เชื่อมต่อ Client Key ของ Flaq.ai
ในแอปเพื่อสร้างและจัดการสื่อภาพ ทั้งนี้แอปเดสก์ท็อปไม่ได้รองรับ API ทุกอย่างบนแพลตฟอร์ม
ดูโมเดลที่พร้อมใช้งานและราคาได้ที่ Flaq.ai

## เกี่ยวกับเทมเพลต

สร้างด้วย Next.js 16, React 19, TypeScript และ Tailwind CSS พร้อมเวิร์กโฟลว์ใช้งานได้ทันที 5 แบบ: ข้อความเป็นภาพ
ภาพเป็นภาพ ข้อความเป็นวิดีโอ ภาพเป็นวิดีโอ และลองเสื้อผ้าเสมือนจริง

### คุณสมบัติหลัก

- 🎨 หน้าสร้างภาพและวิดีโอพร้อมเลือกโมเดลและพารามิเตอร์
- 🔌 เชื่อมต่อ API ของ Flaq.ai ด้วย Client Key เดียว
- 🧠 รองรับ Nano Banana Pro, Seedream, GPT Image, Grok Imagine, Veo, Wan, Kling, Seedance, Vidu และโมเดลอื่น ๆ
- 🌐 รองรับ 15 ภาษาทั้ง UI เส้นทาง และลิงก์ SEO ทางเลือก
- ☁️ อัปโหลด Cloudflare R2 และจัดเก็บผลงานที่สร้าง
- 🔒 จัดเก็บ API key ฝั่งไคลเอนต์แบบเข้ารหัส
- 📱 UI ตอบสนองทุกหน้าจอ โหมดมืด และประวัติการสร้าง

## เริ่มต้นอย่างรวดเร็ว

```bash
git clone https://github.com/flaqai/flaq-saas-template.git
cd flaq-saas-template
pnpm install
cp .env.example .env.local
pnpm dev
```

ตั้งค่า `NEXT_PUBLIC_SITE_URL` ใน `.env.local` และเพิ่มค่าของ Cloudflare R2 เมื่อจำเป็น จากนั้นใส่ Client Key ของ
[Flaq.ai](https://flaq.ai/th/) ในการตั้งค่าแอป
ดูตัวแปรและขั้นตอนทั้งหมดได้ใน[เอกสารภาษาอังกฤษฉบับเต็ม](./README.md#getting-started)

## โปรแกรมพันธมิตร Flaq.ai

ร่วมเป็นพันธมิตร Flaq.ai และรับค่าคอมมิชชันจากการแนะนำเวิร์กโฟลว์ภาพและวิดีโอ AI, API ของโมเดล และเครื่องมือสร้างสรรค์
โปรแกรมนี้เปิดรับครีเอเตอร์ นักออกแบบ นักพัฒนา ผู้สอน AI ผู้รีวิวโมเดล และทีมที่แบ่งปันการใช้งาน AI ในทางปฏิบัติ

- **รางวัลจากการแนะนำ** — รับ 20% จากคำสั่งซื้อแบบชำระเงินที่ถูกต้องครั้งแรกของผู้ใช้ที่แนะนำ และ 10%
  จากคำสั่งซื้อแบบชำระเงินที่ถูกต้องครั้งถัดไปภายใน 60 วันหลังลงทะเบียน ตามกฎคุณสมบัติและการนับผลการแนะนำ
- **โปรโมตได้หลากหลาย** — แชร์ลิงก์แนะนำผ่านบทเรียน รีวิวโมเดล ตัวอย่างผลงาน ชุมชน หรือคู่มือเชื่อมต่อ API
- **พื้นที่ทำงานพันธมิตร** — จัดการลิงก์ ตรวจสอบกิจกรรมการแนะนำ และตั้งค่าการรับเงินบน Flaq.ai

เข้าสู่ระบบ Flaq.ai กรอกโปรไฟล์พันธมิตรและยอมรับข้อตกลง แล้วสร้างลิงก์แนะนำของคุณ
โครงการนี้มีจุดเชื่อมต่อโปรแกรมพันธมิตรหลายภาษา แต่การสมัครและจัดการค่าคอมมิชชันดำเนินการบน Flaq.ai ไม่ใช่ในแอปเดสก์ท็อป
